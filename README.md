# Design and Analysis of Algorithms (DAA)

A collection of algorithm implementations, notes, and problem solutions covering the core concepts taught in a typical **Design and Analysis of Algorithms** course — from asymptotic analysis to advanced algorithmic paradigms.

![Big-O Complexity Comparison](https://commons.wikimedia.org/wiki/Special:FilePath/Comparison_computational_complexity.svg)

## 📌 About

This repository is a study/reference resource for the subject **Design and Analysis of Algorithms (DAA)**. It brings together implementations, explanations, and complexity analysis of the algorithms and techniques commonly covered in the course, making it useful for coursework, revision, and interview preparation.

## 📂 Topics Covered

- **Algorithm Analysis Fundamentals**
  - Time and space complexity
  - Asymptotic notations (Big-O, Big-Ω, Big-Θ)
  - Recurrence relations (Substitution, Recursion Tree, Master Theorem)

- **Divide and Conquer**
  - Merge Sort, Quick Sort
  - Binary Search
  - Strassen's Matrix Multiplication

![Binary Search Complexity](https://commons.wikimedia.org/wiki/Special:FilePath/Binary_search_complexity.svg)

- **Greedy Algorithms**
  - Fractional Knapsack
  - Job Sequencing
  - Huffman Coding
  - Kruskal's & Prim's Algorithms (MST)

- **Dynamic Programming**
  - 0/1 Knapsack
  - Longest Common Subsequence
  - Matrix Chain Multiplication
  - Floyd-Warshall Algorithm

- **Graph Algorithms**
  - BFS, DFS
  - Dijkstra's Algorithm
  - Bellman-Ford Algorithm

- **Backtracking & Branch and Bound**
  - N-Queens Problem
  - Hamiltonian Cycle
  - Traveling Salesman Problem

- **NP-Completeness**
  - P, NP, NP-Hard, NP-Complete classes
  - Reduction techniques
